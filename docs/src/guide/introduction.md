## Xt-PMS 是什么？ {#what-is-xt-pms}

Xt-PMS 是一款专为**国内小微模具制造与注塑企业**量身打造的生产管理系统。系统紧贴行业实际需求，覆盖订单录入、模具档案、工序管理、生产报工、产品交付等全流程环节，助力企业高效完成从订单到交付的数字化管理，实现生产流程的透明化与规范化，推动小微型制造企业的数字化转型。

## 未完善的部分 {#incomplete-parts}

**XT-PMS 目前仍处于持续迭代开发阶段，部分功能尚未完善，部分业务逻辑与实际模具、注塑生产场景仍存在适配优化空间。** 诚邀深耕模具与注塑行业的各位伙伴多多体验试用，欢迎大家结合一线生产实操经验提出宝贵意见与优化建议，助力系统不断贴合行业实际业务需求，打磨更贴合生产现场的专业管理系统。

如果您针对功能、业务流转、操作体验、外观样式等有任何建议，欢迎通过 [Gitee Issues](https://gitee.com/kamyang-tech/xt-pms/issues) 反馈。

您也可以通过 `企业微信` 与我们交流

- **反馈建议** —— 通过 Issue 或 Discussions 与我们交流
