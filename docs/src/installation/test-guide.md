## 一、文档规范说明

### 1.1 测试用例标准字段

| 字段 | 说明 |
|------|------|
| **用例编号** | 全局唯一，格式 `TC_XT_PMS_[模块缩写]_[序号]` |
| **所属模块** | 功能模块或页面 |
| **用例标题** | 一句话概括测试意图，清晰无歧义 |
| **前置条件** | 执行前必须满足的环境、数据、配置、权限等 |
| **测试步骤** | 编号分步描述，每步只写一个动作（操作+输入数据） |
| **测试数据** | 具体输入值，禁止写"输入合法数据"等模糊描述 |
| **预期结果** | 可判定、可观察的具体现象（UI提示/数据库变更/接口返回） |
| **优先级** | P0 / P1 / P2 / P3 |
| **用例类型** | 功能测试 / 边界值测试 / 异常测试 / 权限测试 / 状态流转测试 |

### 1.2 优先级定义

| 优先级 | 定义 | 测试策略 |
|--------|------|----------|
| **P0** | 核心主流程，失败会导致测试阻塞或产品无法发布 | 必须100%通过，任何失败立即修复 |
| **P1** | 重要功能模块，影响用户主要体验或业务指标 | 必须执行，允许非阻塞性缺陷 |
| **P2** | 一般功能、次要页面、常规异常处理 | 常规轮次执行，时间紧张可抽样 |
| **P3** | 界面细节、文案、极边缘场景 | 视项目周期而定，回归阶段抽查 |

### 1.3 通用页面交互规范（所有列表页适用）

以下规范适用于系统内所有含表格的列表页面，不在各模块中重复赘述：

**GT-001 通用规范 - 列表页基础交互**

| 项目 | 说明 |
|------|------|
| **搜索** | 输入条件后点击"搜索"按钮，表格数据按条件过滤，分页重置到第1页 |
| **重置** | 点击"重置"按钮，清空所有搜索条件，表格恢复默认查询（第1页） |
| **刷新** | 点击"刷新"按钮，重新加载当前页数据 |
| **列设置** | 点击"列设置"按钮，弹出列设置对话框，可勾选/取消勾选显示列，调整列顺序，保存后 localStorage 持久化 |
| **分页** | 默认每页20条，可选10/20/50/100条；切换页码或每页条数触发重新查询 |
| **批量操作** | 勾选表格左侧复选框，顶部出现批量操作栏；显示"已选择 N 项" |
| **权限控制** | 所有新增/编辑/删除/操作按钮均受 `v-permission` 控制，无权限时不显示；超级管理员不受限制 |
| **表格排序** | 部分列头支持点击排序，切换升序/降序 |
