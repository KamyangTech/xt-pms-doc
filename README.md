# Xt-PMS 文档站点

小微模具注塑企业专用生产管理系统（Xt-PMS）的官方文档站点。

基于 [VitePress](https://vitepress.dev/) + Vue 3 构建，部署于 [Cloudflare Pages](https://pages.cloudflare.com/)。

## 本地开发

```bash
cd docs
pnpm install
pnpm run dev
```

## 构建

```bash
cd docs
pnpm run build
pnpm run preview
```
